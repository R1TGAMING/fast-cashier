## 📋 Requirements
- typescript>=6.0.3
- node>=26.13.1

## 🔧 How To Use
1. clone this repository
```bash
git clone https://github.com/R1TGAMING/fast-cashier.git
```
2. change to project directory
```bash
cd fast-cashier
```
3. install the depedencies
```bash
npm install
```

4. build the typescript
```bash
npx tsc
```
5. run the program
```bash
node dist/index.ts
```
done.
